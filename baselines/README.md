# Baselines

This directory contains the public baseline adapters used in the paper-aligned
comparison setup.

- `pentestagent.py`: adapted PentestAgent-style pipeline for the shared lab.
- `vulnbot.py`: adapted VulnBot-style pipeline for the shared lab.

These are adaptation layers, not claims of exact source-level reproduction of
the original external projects. They should be evaluated only under the shared
external outcome protocol described in the root README.
